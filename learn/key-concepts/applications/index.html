What ML actually does.

Looping animations of where deep learning lands — classification, regression, segmentation, computer vision, NLP, robotics, GANs, and diffusion. Concrete tasks, not theory.

← LEARN / Core DL Agentic & LLM Applications
// SUPERVISEDLIVE

Classification

argmax p(y | x)

Input → model → probability over a fixed set of classes. The winner gets the label; everything else is a runner-up.

// SUPERVISEDLIVE

Regression

ŷ = f(x) ∈ ℝ

Predict a continuous value. The model fits a curve through noisy data, minimizing the mean squared error.

// DENSE PREDICTIONLIVE

Segmentation

PIXEL-WISE CLASSIFICATION

Label every pixel. Each region of the image gets a class — sky, ground, object — building a colored mask.

// DETECTIONLIVE

Computer Vision

OBJECT DETECTION · bbox + class

Find and box every object in the frame. Each detection has a class label and a confidence score.

// TEXTLIVE

Natural Language

TOKENS → EMBEDDINGS → TASK

Text gets tokenized, embedded into vectors, processed by a transformer, and mapped to a task output — sentiment, translation, summary.

// CONTROLLIVE

Robotics

π(a | s) · POLICY LEARNING

Sensors → state → policy network → action. The model learns to map perceived state to motor commands that maximize reward.

// GENERATIVELIVE

GAN

GENERATOR ⇄ DISCRIMINATOR

Two networks compete. G tries to fool D with fake samples; D tries to spot them. Both improve together — an arms race.

// GENERATIVELIVE

Diffusion

T → 0 · ITERATIVE DENOISING

Start with pure noise. At each step, predict the noise to remove. After T iterations, a clean image emerges from chaos.
